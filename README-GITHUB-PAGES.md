## Publish with GitHub Pages
1. Sign in to GitHub and create a new **Public** repository, for example `asad-portfolio`.
2. Keep the repository name as `asad-portfolio` (or choose another name).
3. On the repository page, choose **Add file → Upload files**.
4. Extract this ZIP on your computer.
5. Upload `index.html` and the complete `assets` folder (including `asad-profile.png`) to the repository root.
6. Scroll down and click **Commit changes**.
7. Open **Settings → Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Select branch **main** and folder **/(root)**, then click **Save**.
10. Wait a few minutes. GitHub will show your published website address in the Pages section.

For a repository named `asad-portfolio`, the address will usually be:
`https://YOUR-GITHUB-USERNAME.github.io/asad-portfolio/`

For a custom domain such as `asadiqbal.com`, configure the domain under **Settings → Pages → Custom domain** and update your DNS records as GitHub instructs.

## Important
- Keep `index.html` and the `assets` folder at the same repository level.
- Do not rename `asad-profile.png` unless you also update its path in `index.html`.
- Before publishing, replace the placeholder LinkedIn link and email address in the Contact section with your real public details.
